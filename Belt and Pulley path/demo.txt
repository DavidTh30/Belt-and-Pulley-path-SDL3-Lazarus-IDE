# Belt and Pulley Path - animation script
#
#   node   <node> <x> <y> <r>               start position/radius (optional)
#   line   <node> <x> <y> <seconds>          move in a straight line (eased)
#   move   <node> <x> <y> <seconds>          move in a straight line (constant speed)
#   orbit  <node> <center> <turns> <seconds> orbit around node <center> (+ = clockwise)
#   radius <node> <r> <seconds>              change radius
#   hold   <seconds>                         stand still
